## 🗺️ Lộ Trình 3 Giai Đoạn (Tổng thời gian: ~2 tiếng)

### GIAI ĐOẠN 1: Phát Triển Ứng Dụng Web (Tại `E:\SELF-STUDY\ghost-in-the-machine`)
- ✅ Khởi tạo Vite + React 19 + Tailwind CSS v4.
- ✅ Viết `aiService.js`: Kết nối Google Gemma 2 & Meta Llama 3 qua Groq, kèm bộ dự phòng offline 20+ truyện ma.
- ✅ Viết `soundService.js`: Bộ phát âm thanh ma quái Web Audio API và giọng đọc nguyền rủa.
- ✅ Dựng UI `GhostTerminal.jsx`: Màn hình CRT scanlines, nút "Triệu hồi truyện ma", máy đánh chữ.
- 🔄 **Hiện tại:** Bạn đang xem xét mã nguồn (`aiService.js`) và giao diện để góp ý chỉnh sửa.
